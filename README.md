# BA-Spine-Viewer-Asset

Asset repository for [BA-Spine-Viewer](https://github.com/baecha-samcha/BA-Spine-Viewer), a fan-made Blue Archive Spine viewer.
It is a fork of [asdfdsa12/BA-Spine-Viewer-Asset](https://github.com/asdfdsa12/BA-Spine-Viewer-Asset).

This is a historical repository. It is archived and no longer maintained.
